# Blog System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a weekly blog system where articles are written as `.mdx` files and served at `/blog/:slug` with rich content support.

**Architecture:** Each article is a `.mdx` file in `src/content/blog/` with YAML frontmatter (title, date, slug, description, author). A dynamic Vite glob import maps slugs to modules. `BlogLayout` wraps all articles with the existing design system. `BlogPost` page handles routing and lazy-loading.

**Tech Stack:** MDX + @mdx-js/rollup, remark-frontmatter, remark-mdx-frontmatter, React Router v7, Framer Motion, Tailwind CSS v4 (custom tokens)

### Task 5: Create BlogPost page (dynamic route handler)

**Files:**
- Create: `src/pages/BlogPost.tsx`

- [ ] **Step 1: Create src/pages/BlogPost.tsx**

```tsx
import { Suspense, lazy, useMemo } from "react"
import { useParams, Navigate } from "react-router-dom"
import { BlogLayout } from "@/layouts/BlogLayout"

type MDXModule = {
  default: React.ComponentType
  frontmatter: {
    title: string
    date: string
    slug: string
    description: string
    author: string
  }
}

const modules = import.meta.glob<MDXModule>("../content/blog/*.mdx")

function slugToPath(slug: string): string {
  return `../content/blog/${slug}.mdx`
}

export function BlogPost() {
  const { slug } = useParams<{ slug: string }>()

  const path = slug ? slugToPath(slug) : null
  const loader = path ? modules[path] : undefined

  if (!loader) {
    return <Navigate to="/" replace />
  }

  const Article = lazy(loader)

  return (
    <Suspense fallback={<div className="min-h-screen bg-[var(--c-bg)]" />}>
      <ArticleWrapper Article={Article} loader={loader} />
    </Suspense>
  )
}

function ArticleWrapper({
  Article,
  loader,
}: {
  Article: React.ComponentType
  loader: () => Promise<MDXModule>
}) {
  const [fm, setFm] = useMemo(() => {
    let fm: MDXModule["frontmatter"] | null = null
    loader().then((mod) => { fm = mod.frontmatter })
    return [fm, (v: MDXModule["frontmatter"]) => { fm = v }]
  }, [loader])

  // Re-render once frontmatter resolves
  const [resolved, setResolved] = useMemo(() => {
    let resolved = false
    return [resolved, (v: boolean) => { resolved = v }]
  }, [])

  if (!fm) {
    // frontmatter not yet resolved — render after Suspense hydrates
    loader().then(() => {})
    return null
  }

  return (
    <BlogLayout
      title={fm.title}
      date={fm.date}
      author={fm.author}
      description={fm.description}
    >
      <Article />
    </BlogLayout>
  )
}
```

> **Note:** The pattern above has a timing issue with frontmatter loading. Replace `BlogPost.tsx` entirely with this cleaner async approach using a module cache:

```tsx
import { Suspense, lazy, useState, useEffect } from "react"
import { useParams, Navigate } from "react-router-dom"
import { BlogLayout } from "@/layouts/BlogLayout"

type Frontmatter = {
  title: string
  date: string
  slug: string
  description: string
  author: string
}

type MDXModule = {
  default: React.ComponentType
  frontmatter: Frontmatter
}

const modules = import.meta.glob<MDXModule>("../content/blog/*.mdx")

export function BlogPost() {
  const { slug } = useParams<{ slug: string }>()
  const [frontmatter, setFrontmatter] = useState<Frontmatter | null>(null)
  const [notFound, setNotFound] = useState(false)

  const path = slug ? `../content/blog/${slug}.mdx` : null
  const loader = path ? modules[path] : undefined

  useEffect(() => {
    if (!loader) {
      setNotFound(true)
      return
    }
    loader().then((mod) => setFrontmatter(mod.frontmatter))
  }, [loader])

  if (notFound) return <Navigate to="/" replace />
  if (!frontmatter) return <div className="min-h-screen bg-[var(--c-bg)]" />

  const Article = lazy(loader!)

  return (
    <BlogLayout
      title={frontmatter.title}
      date={frontmatter.date}
      author={frontmatter.author}
      description={frontmatter.description}
    >
      <Suspense fallback={null}>
        <Article />
      </Suspense>
    </BlogLayout>
  )
}
```

## How to Add Future Articles

Each new article follows this pattern:

1. Create `src/content/blog/tu-titulo-aqui.mdx`
2. Add frontmatter at the top:
```md
---
title: "Tu título aquí"
date: "2026-04-17"
slug: "tu-titulo-aqui"
description: "Una línea que resume el artículo"
author: "Oscar" 
---
```
3. Write content in Markdown below the frontmatter
4. Article is live at `/blog/tu-titulo-aqui` immediately — no code changes needed
